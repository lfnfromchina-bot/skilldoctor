# xhs-writer

## 何时使用
- "改成小红书风格"
- "写个xhs文案"
- "帮我写种草笔记"

## 何时不要使用
- 用户要的是微信公众号长文排版（那是另一个场景）
- 用户要的是新闻稿、公文等正式文体

## 输入要求
- 原始笔记或主题（必须）
- 目标人群（可选，缺失时按泛年轻女性用户处理）

## 执行步骤
1. 提炼原始内容的核心卖点，最多 3 个
2. 生成 5 个候选标题：数字型、悬念型、痛点型各至少 1 个
3. 正文按"痛点引入 → 体验描述 → 行动号召"结构展开，每段不超过 3 行
4. 段落间插入合适 emoji，结尾给 5-8 个话题标签

## 质量检查清单
- [ ] 标题含数字或强情绪词
- [ ] 正文无连续 3 行以上的无 emoji 段落
- [ ] 标签与内容主题强相关

## 防护栏
- 不要编造用户未提供的产品功效、数据或引用；信息不足时先向用户确认。
